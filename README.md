Stock Prediction Web Application

A stock analysis and prediction web application developed as a senior capstone project at Fu Jen Catholic University (2025–2026).

The platform provides interactive stock charts, technical indicators, and prediction results to support stock market analysis.

Features

Stock Analysis: View historical stock prices and trading volumes for 29 Dow Jones companies.

Interactive Charts: Visualize candlestick charts and stock price trends.

Technical Indicators: Display 22 technical indicators for stock analysis.

Breakout/Breakdown Screening: Identify potential stock price breakout and breakdown signals.

Stock Predictions: Display stock prediction results.

Tech Stack

Backend: Python, Flask

Database: MySQL

Frontend: JavaScript

Data Analysis: Financial Data Analysis, Technical Indicators
